# Resume vs Job Description Matcher

A Node.js CLI tool that compares a resume to a job description and returns a match score based on keyword matching.

## Usage

1. Prepare your resume and job description as plain text files (`resume.txt` and `job.txt`).
2. Run the script:

```bash
node match.js resume.txt job.txt
```
3. The script will output a match score:
Match Score: 72.50% (Example)

**Requirements**
Node.js
